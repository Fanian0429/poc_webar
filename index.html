Camera Controls

W: Move forward
A: Strafe left
S: Move backward
D: Strafe right
Q: Move down
E: Move up
Left Click: Look around in place
Right Click: Orbit around the model
Shift + Right Click: Pan the view
Shift + WASD/QE: Move faster while flying

Model Status & Troubleshooting

The last line of the status text at the top of the screen shows the current model status and guidance.

If you can't see the model correctly, try the following:

  1. The model file is fairly large, so please allow some time for it to finish loading.
  2. If the text in the upper-left shows "Point your phone at...", follow that instruction.
  3. Tap "Place Here" to place the model directly in front of you.
  4. If none of the above works, reload the page or check your network connection.
